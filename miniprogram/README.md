# 微信小程序端

微博热搜提醒的小程序客户端。微信开发者工具打开**仓库根目录**即可识别：

```text
miniprogramRoot = miniprogram/
cloudfunctionRoot = cloudfunctions/
```

## 页面

- **首页**：登录状态、今日命中/观察中/提醒额度统计、最近命中、当前热搜榜 Top10、工具广场
- **订阅**：订阅规则列表，启停开关，点击进入编辑
- **新建/编辑订阅**：关键词（支持 `prefix:`/`regex:`）、排除词、标签胶囊（爆/沸/热/新）、最低热度、通知通道选择、**预览命中**（试跑当前热搜）、删除
- **命中**：命中事件列表（全部/今日/已通知/未通知筛选），展示排名、热度、观察次数、通知状态与未通知原因；点击条目查看排名趋势
- **我的**：用户信息、提醒额度与「开启提醒」授权、通道测试与启停、抓取状态、退出登录
- **热搜趋势**（工具）：关键词排名历史查询（24h/3天/7天）
- **计算器**（工具）：本地四则运算
- 工具广场支持第三方小程序跳转位：在 [config.js](./config.js) 的 `THIRD_PARTY_TOOLS` 填入目标 appId 即出现入口（如天气/汇率类小程序）

## 登录态

- 启动时静默登录：`wx.login` → `POST /api/auth/wx-login` → 保存主服务 JWT
- 所有请求带 `Authorization: Bearer <token>`，401 时自动重新登录并重试一次

## 联调配置

- 主服务地址在 [config.js](./config.js)：开发版自动用 `http://127.0.0.1:8080`（工具中勾选「不校验合法域名」），体验版/正式版用 `PROD_API_BASE_URL`
- 上线前须在小程序后台「开发设置-服务器域名」把生产 HTTPS 域名加入 request 合法域名
- `project.config.json` 的 `appid` 需替换为自己的小程序 AppID
- 「开启提醒」依赖服务端配置 `WX_SUBSCRIBE_TEMPLATE_ID`（小程序后台「订阅消息」申请模板）
